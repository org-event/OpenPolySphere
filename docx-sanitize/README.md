# sanitize_docx.py — полная санитизация DOCX

Обезличивает `.docx` / `.docm`, сохраняя шаблон (вёрстка, стили, размеры).

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
python3 sanitize_docx.py договор.docx
# → договор.sanitized.docx

python3 sanitize_docx.py договор.docx -o clean.docx
python3 sanitize_docx.py договор.docx --seed 42
```

## Что санитизируется

| Контент | Действие |
|---------|----------|
| Текст в теле, колонтитулах, сносках, комментариях, фигурах, графиках | Слово/число → случайные символы **той же длины** (кириллица/латиница/цифры, регистр) |
| Пробелы и пунктуация | Не меняются |
| PNG / JPEG / GIF / BMP / TIFF / WEBP | Плейсхолдер **тех же пикселей** |
| **EMF / WMF / EMZ / WMZ / SVG** | Пустой плейсхолдер **тех же размеров** (bounds/frame) |
| Прочие файлы в `word/media/` | Обнуление байтов (длина та же) |
| OLE / embeddings | Обнуление |
| Alt-text, title, tooltip у картинок/фигур | Скремблинг |
| Внешние гиперссылки в `.rels` | Схема сохраняется, остальное скремблится |
| `docProps` (автор, компания, название…) и thumbnail | Скремблинг / замена |

Структура OOXML (ZIP) не пересобирается заново — меняется только содержимое частей.
